# NewProject

Trading dashboard UI demo bertema dark mode dengan komponen utama:

- Watchlist pair crypto
- Mock chart area dengan timeframe selector
- Ringkasan metrik akun (balance, PnL, margin)
- Order book (ask/bid)
- Quick order form
- Open positions table

## Menjalankan project

Cukup buka file `index.html` langsung di browser, atau jalankan server lokal sederhana:

```bash
python3 -m http.server 4173
```

Lalu akses `http://localhost:4173`.
